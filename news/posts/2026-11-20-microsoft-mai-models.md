## 이번 주 핵심 뉴스

- 마이크로소프트가 11월 17일 Ignite 2026에서 자체 개발한 MAI 모델 7종을 공개했습니다.
- 코딩 모델 MAI Code 2는 GPT-6.1 Sol 코딩 품질의 98%를 약 40% 가격에 낸다고 밝혔고, MAI Code 2와 Code 2 Flash는 GitHub Copilot에서 쓸 수 있습니다.
- 보안(MAI Cyber 2 Flash), 이미지(MAI Image 2.7), 실시간 음성(MAI Realtime 1, 분당 0.01달러부터), 요청을 큰 모델로 넘길지 정하는 라우팅용 Decision 1.1 등도 함께 나왔습니다.
- 성능·가격 비교는 모두 마이크로소프트의 자체 주장이며, 독립 검증은 아직 확인하지 못했습니다.

## 왜 눈여겨봤나

이번 발표의 초점은 가장 똑똑한 모델이 아니라 비슷한 품질을 더 싸게 쓰는 것이었습니다. 코딩, 보안, 이미지, 음성, 라우팅까지 용도별로 모델을 나눠 놓았다는 점도 눈에 띕니다. 작은 팀에는 선택지가 늘어나는 소식이지만, 숫자가 발표 자료 기준이라 직접 써 보기 전에는 판단을 미루는 편이 안전합니다.

## 시노우랩스가 느낀 점

모델이 다양하고 저렴해질수록 어떤 일에 AI를 붙이느냐가 더 중요해진다고 느꼈습니다. 하비허브는 7일마다 Gemini가 활동을 분석해 피드백을 줍니다. 이런 주기적인 분석 작업은 모델 가격 차이가 비용에 바로 닿는 자리라, 용도별 모델이 늘어나는 흐름을 계속 지켜보려 합니다.

반대로 약봄의 복약 알람은 화면이 꺼져 있어도 잠금 화면 위로 약 이름과 복용 완료 버튼만 보여 주는 것이 핵심입니다. 여기서는 똑똑함보다 틀리지 않는 것이 먼저라서, 새 모델 소식과 상관없이 단순함을 지키는 쪽이 맞다고 생각합니다.
