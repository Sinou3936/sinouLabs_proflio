## 이번 주 핵심 뉴스

- Anthropic이 11월 9일(현지 기준) Claude Fable 5.2와 Mythos 5.2를 공개했습니다.
- Fable 5.2는 API 모델명 `claude-fable-5-2`로 쓸 수 있고, AWS·Google Cloud·Microsoft Azure에서도 제공됩니다.
- API 단가는 입력 100만 토큰당 8달러, 출력 40달러입니다. 한 매체는 이전 세대(입력 10달러, 출력 50달러)보다 낮아졌다고 보도했습니다.
- 이전 버전보다 출력이 최대 30% 빠르고, 중간 노력 수준에서는 토큰을 더 적게 쓴다고 Anthropic은 밝혔습니다. 성능 수치는 회사 자체 결과이며 독립 검증은 아직 없습니다.

## 왜 눈여겨봤나

새 모델이 나올 때 성능 이야기가 먼저 나오지만, 1인 개발자에게는 단가와 응답 속도, 토큰 사용량이 더 직접적인 문제입니다. 이번 발표는 세 가지가 함께 언급되어 비교해 볼 만했습니다.

## 시노우랩스가 느낀 점

하비허브는 7일마다 Gemini가 활동을 분석해 피드백을 주는 구조라, 어느 회사 모델이든 단가와 모델 교체 소식이 남의 일이 아닙니다. 새 모델이 나올 때마다 가격이 내려가는 흐름이라면 같은 비용으로 더 나은 피드백을 받을 여지도 생깁니다. 반대로 모델 이름이 코드 곳곳에 흩어져 있으면 갈아타기 어렵습니다.

그래서 이번에도 결론은 비슷합니다. 모델 이름과 호출 설정을 한곳에서 관리하고 있는지, 새 모델로 바꿨을 때 피드백 품질과 비용을 비교해 볼 수 있는지 점검해 보려 합니다. 벤치마크는 회사가 직접 낸 수치이니, 제 앱의 실제 입력으로 확인하기 전에는 판단을 미루려 합니다.

약봄은 모델 호출이 중심인 앱이 아니라 이번 소식과 직접 연결되지는 않습니다.
